Página de prueba del chat web

Esta página carga dist/cauce-widget.js como lo haría una tienda: una sola etiqueta <script> con la clave pública del canal. Ábrela con ?key=pk_…&instance=http://localhost:8080. Ejecuta antes npm run build.

El contenido de la página no debe quedar tapado: el botón del chat vive en una esquina y el panel solo aparece al abrirlo.
